# Дневник Трейдера
***
Приложение, которое позволяет вести свой дневник сделок.
А так же анализировать, смотреть статистику.
Приложение позволяет установить лимт сделок на день,
лимит BAD сделок, чтобы не потерять прибыль. Очень подоходит для
RISK MANAGEMENT
---
**Будущие планы:**
- Интеграция с API Т-Инвестиций
- AI для анализа и отчета ваших сделок (Только анализ, не рекомендации по сделкам)
